# Offline Music Player

A personal offline music player built using **Python**, **Tkinter**, and **Pygame**.

## Features

- Add MP3 files to your music library
- Play, pause, resume, and stop songs
- Play the next or previous song
- Shuffle playback
- Automatically play the next song when the current one finishes
- Remove songs from the library
- Save and load the music library locally

## Technologies Used

- Python
- Tkinter
- Pygame

## How to Run

1. Clone this repository.
2. Install the required dependency:

   ```bash
   pip install pygame-ce
   ```

3. Run the application:

   ```bash
   python project_spotify.py
   ```

## Note

This application plays local MP3 files. Add your own music files through the application.
